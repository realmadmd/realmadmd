### 01 — DoctorSpace

**Healthcare management platform for modern clinics**

<div align="center">

<a href="https://doctorspace.pk"><img src="https://image.thum.io/get/width/1000/crop/520/noanimate/https://doctorspace.pk" alt="DoctorSpace preview" width="820" /></a>

<img src="https://img.shields.io/badge/Next.js-%E2%80%A2-NestJS-%E2%80%A2-PostgreSQL-111827?style=for-the-badge&labelColor=0F172A" alt="Stack" />

#### Overview

DoctorSpace is a comprehensive healthcare platform built for clinics and patients. It combines appointment booking, doctor discovery, digital prescriptions, lab tests, and multi-role clinic operations into one production product experience.

#### Problem Solved

Clinics often run on fragmented tools — phone bookings, paper records, disconnected billing, and no patient portal. DoctorSpace unifies those workflows into a single digital system.

#### Product Highlights

| Area | Capabilities |
| --- | --- |
| Clinic Ops | Doctor and staff management, multi-role access |
| Patient Care | Records, appointments, digital prescriptions |
| Diagnostics | Lab test booking (home / in-clinic) |
| Discovery | Specialty browsing across care categories |
| Engagement | Health calculators, blogs, patient portal |
| Business | Billing, reporting, operational visibility |

#### Architecture Notes

- Multi-role access for doctors, staff, and patients
- Appointment and prescription workflows for real clinic operations
- Mobile-friendly patient journeys with secure data handling
- Built as a production healthcare product, not a brochure site

**Stack:** Next.js · NestJS · PostgreSQL · TypeScript · RBAC  
**Live:** [doctorspace.pk](https://doctorspace.pk)

**Digital platform for a world-class nightlife venue experience**

#### Overview

FVTURE is the digital product layer for Bangkok’s FVTURE hyperclub — covering event discovery, ticket booking, VIP table reservations, content, and companion mobile access for a high-capacity venue experience.

#### Problem Solved

Premium nightlife needs more than a static website. Guests need fast ticket purchase, VIP booking, event updates, and a branded experience that matches the venue’s physical quality.

#### Product Highlights

| Area | Capabilities |
| --- | --- |
| Events | Schedules, artist / DJ discovery |
| Ticketing | Entry ticket booking and purchase flow |
| VIP | Table reservations and premium hospitality |
| Content | Blog / editorial venue storytelling |
| Mobile | Companion app for tickets and updates |
| Experience | Immersive brand-led product UX |

#### Architecture Notes

- Consumer booking and reservation flows under event-driven demand
- Web and mobile surfaces for one venue ecosystem
- High-intent conversion design: book table / book ticket
- Content, commerce, and event operations in one product

**Stack:** Modern web stack · APIs · Mobile companion · Cloud deployment  
**Live:** [fvture.co](https://fvture.co)

| Phase | What Happens |
| --- | --- |
| 01 Discover | Understand goals, users, constraints, and success metrics |
