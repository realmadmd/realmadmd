I'm **Daud Ahmed** — a **Full Stack Architecture Developer** focused on designing and shipping scalable digital products for startups, businesses, and enterprises.

My philosophy is simple:

### Overview

DoctorSpace is a comprehensive healthcare platform built for clinics and patients — combining appointment booking, doctor discovery, digital prescriptions, lab tests, and multi-role clinic operations into one product experience.

### Product Highlights

| Area | Capabilities |
| :--- | :--- |
| **Clinic Ops** | Doctor management, staff management, multi-role access |
| **Patient Care** | Patient records, appointments, digital prescriptions |
| **Diagnostics** | Lab test booking (home / in-clinic) |
| **Discovery** | Specialty browsing — dental, gynae, physio, nutrition, and more |
| **Engagement** | Health calculators, blogs, patient portal experiences |
| **Business** | Billing, reporting, and operational visibility |

### Architecture Notes

- Multi-role access for doctors, staff, and patients  
- Appointment + prescription workflows designed for real clinic operations  
- Mobile-friendly patient journeys with secure health data handling  
- Built as a production healthcare product, not a brochure site  

### Stack

`Next.js` · `NestJS` · `PostgreSQL` · `TypeScript` · `Role-based access`

**Live:** [doctorspace.pk](https://doctorspace.pk)

### Overview

FVTURE is the digital product layer for Bangkok’s FVTURE hyperclub — a high-capacity nightlife venue experience covering event discovery, ticket booking, VIP table reservations, content, and companion mobile access.

### Product Highlights

| Area | Capabilities |
| :--- | :--- |
| **Events** | Upcoming events, artist/DJ discovery, schedule surfaces |
| **Ticketing** | Entry ticket booking with a direct digital purchase flow |
| **VIP** | Table reservations and premium hospitality experiences |
| **Content** | Blog / editorial surfaces for venue storytelling |
| **Mobile** | Companion app for tickets, VIP booking, and updates |
| **Experience** | Immersive brand-led UX aligned with a premium venue |

### Architecture Notes

- Consumer-facing booking and reservation flows under event-driven demand  
- Web + mobile product surface for the same venue ecosystem  
- Designed for high-intent conversion: book table / book ticket  
- Content, commerce, and event operations in one digital experience  

### Stack

`Next.js` / modern web stack · APIs · Mobile companion · Cloud deployment
